| Término | Definición | Evitar |
| --- | --- | --- |
| Organización | Negocio cliente que opera el servicio. | Empresa/negocio en texto normativo. |
| Sucursal | Ubicación operativa de una Organización. | Sede sin definición. |
| Superadministrador | Rol global que gestiona la plataforma SaaS y el onboarding de Organizaciones. | Admin global. |
| Administrador de organización | Rol que configura y opera el sistema para una Organización. | Admin local. |
| Recepcionista | Rol que gestiona la agenda, reservas, clientes y lista de espera de una o varias Sucursales. | Secretario. |
| Profesional | Persona que presta un servicio. | Empleado cuando no presta servicio. |
| Recurso reservable | Activo que ocupa una reserva (equipo, sala, instrumento). | Recurso sin contexto. |
| Servicio | Prestación que determina duración y disponibilidad. | Producto. |
| Especialidad | Área de competencia de un Profesional que determina qué Servicios puede prestar. | Habilidad sin contexto. |
| Cliente | Persona que solicita una Reserva. | Usuario final ambiguo. |
| Agenda | Vista organizada de las Reservas, Bloqueos y franjas disponibles de un Profesional o Sucursal en un período. | Calendario sin contexto. |
| Disponibilidad | Franjas ofertadas para reservar. | Horario libre. |
| Franja horaria | Intervalo de tiempo concreto (fecha, hora inicio, hora fin) que puede ser reservado o bloqueado. | Slot sin traducción. |
| Horario general | Configuración de apertura y cierre de una Sucursal por día de la semana. | Horario base. |
| Bloqueo | Período en que un Profesional o Sucursal no está disponible para reservas (ausencia, permiso, mantenimiento). | Día libre sin contexto. |
| Reserva | Compromiso confirmado de servicio/recurso y franja. | Turno sin contexto. |
| Reprogramación | Cambio de fecha, hora o profesional de una Reserva existente. | Reagendamiento. |
| Cancelación | Anulación de una Reserva antes de su ejecución. | Baja. |
| No-show | Reserva no ejecutada ni cancelada en la que el Cliente no asiste. | Ausencia sin registro. |
| Lista de espera | Solicitudes pendientes para una franja o servicio. | Cola sin prioridad. |
| Reasignación automática | Propuesta al candidato elegible tras liberación. | Confirmación implícita. |
| Canal de notificación | Medio elegido para comunicar (WhatsApp, Telegram, correo electrónico, SMS). | Mensaje. |
| Rol | Conjunto de permisos que determinan qué acciones y datos puede acceder un usuario del sistema. | Perfil sin control. |
| Política de organización | Regla configurable por la Organización (plazos de cancelación, límites de reservas, ventana de programación). | Configuración sin alcance. |
| Panel / Dashboard | Vista resumen con métricas clave de operación, ocupación y rendimiento. | Tablero sin definición. |
